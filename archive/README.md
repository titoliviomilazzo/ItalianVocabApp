# archive/

**Dammi Parole** 앱을 만드는 과정에서 사용한 작업 산출물을 보존하는 폴더입니다.
앱 실행에는 필요 없지만, "어떻게 만들었는지"의 기록으로 남깁니다.

- **`prompts/`** — Genspark 4컷 만화 생성용 프롬프트 배치 (`genspark_prompts_*`, `csv_prompts_*`)
- **`scripts/`** — 데이터 가공·프롬프트 생성 Python 스크립트, 동기화 헬퍼
- **`data/`** — 원본 어휘 CSV (_Nuovo Vocabolario di Base_ 등)
